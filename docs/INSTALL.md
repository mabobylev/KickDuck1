# Установка KickDuck1 1.0.0

## Требования

- Linux x86-64 с графической сессией X11 или совместимым XWayland.
- DAW с Linux VST3 и поддержкой внешнего sidechain; проверено пользователем в REAPER.
- Для текущего бинарного пакета: glibc 2.43+ и libstdc++ с GLIBCXX_3.4.32 и CXXABI_1.3.15.
  Это требования собранных файлов, а не минимальные требования исходного кода.
- Системные библиотеки ALSA, fontconfig, FreeType и их зависимости.
  Точный перечень и версии символов записаны в BUILD_INFO.json пакета.

На других дистрибутивах бинарная совместимость не проверялась. Если DAW
не может загрузить библиотеку, соберите проект локально по README.
Windows, macOS и ARM в этот пакет не входят.

## Установка VST3

1. Распакуйте архив в отдельную папку.
2. Закройте экземпляры KickDuck1 и DAW перед заменой установленного плагина.
3. Если KickDuck1 уже установлен, сохраните копию старой папки перед обновлением.
4. Скопируйте **всю папку** `KickDuck1.vst3` в `~/.vst3/`, не только файл `.so`.
5. Откройте DAW и обновите список VST3. Добавьте **VST3: KickDuck1 (KickDuck)**.

Для первой установки из распакованной папки:

```sh
mkdir -p "$HOME/.vst3"
cp -a KickDuck1.vst3 "$HOME/.vst3/"
```

Проверьте бинарные зависимости при ошибке загрузки:

```sh
ldd "$HOME/.vst3/KickDuck1.vst3/Contents/x86_64-linux/KickDuck1.so"
```

`not found` или ошибка версии GLIBC/GLIBCXX означают несовместимую среду.
Не заменяйте системную glibc отдельными файлами плагина: используйте локальную
сборку или совместимую систему.

## Настройка в REAPER

1. Добавьте KickDuck1 на басовую дорожку после инструмента.
2. Откройте маршрутизацию басовой дорожки и выделите четыре аудиоканала.
3. Создайте send с дорожки кика на бас: **Audio 1/2 → 3/4**.
   Основной бас остаётся на каналах 1/2.
4. В pin connector плагина проверьте назначение основного входа на 1/2,
   входа Kick Sidechain на 3/4 и выхода на 1/2. Случайное направление
   кика в основной вход будет добавлять его к басу.
5. Выберите **AUDIO**, запустите воспроизведение и убедитесь, что оранжевая
   волна кика и GR реагируют на удары. Начальная форма — Classic, Amount 70%.

Для ducking без кика выберите **HOST SYNC**. Этот режим работает по
транспорту независимо от того, оставил ли REAPER AUX-шину включённой.
В AUTO выбор зависит от включённой шины AUX, а не наличия send или
тишины между ударами. Удаление send само по себе может не отключить AUX.

## Standalone

`Standalone/KickDuck1` — самостоятельное приложение для проверки интерфейса
и аудиоустройства. При запуске настройте устройство и каналы. Оно не получает
транспорт, BPM и маршрутизацию проекта REAPER; для полноценной DAW-работы
используйте VST3. Standalone не является отдельной DAW.

## Контрольные суммы и удаление

До распаковки можно сверить архив по соседнему `.sha256` файлу. После распаковки:

```sh
sha256sum -c SHA256SUMS
```

Для удаления закройте DAW и удалите только установленную папку
`~/.vst3/KickDuck1.vst3`. Собственные `.kickduckpreset` файлы и проекты
DAW не удаляются установкой и должны храниться отдельно.
