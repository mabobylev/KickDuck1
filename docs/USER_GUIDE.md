# KickDuck1 — руководство

KickDuck1 освобождает место для кика, управляя уровнем баса по редактируемой
кривой. Основной вход принимает бас, отдельный AUX — управляющий сигнал кика.
Кик не подмешивается в выход.

## Быстрый старт

Настройте sidechain по [INSTALL.md](INSTALL.md), выберите AUDIO и начните
с Classic и Amount 70%. Уменьшите Amount, если бас проваливается слишком
сильно. Перемещайте точки для выбора характера восстановления. Для сравнения
скопируйте A в B, измените B и переключайтесь между ними.

## Режим и длительность цикла

| Режим | Запуск кривой |
|---|---|
| AUTO | AUDIO при включённом AUX, HOST SYNC при отключённом |
| AUDIO | Каждый распознанный удар в AUX; без кика нового запуска нет |
| HOST SYNC | Сетка транспорта хоста, независимо от AUX |

Тишина на подключённом AUX не переключает AUTO на HOST SYNC. В HOST SYNC
остановка транспорта отпускает подавление. Без PPQ во время playing используется
свободный темповый цикл; без BPM — 120 BPM. Перемотка/loop переустанавливают фазу.

| Деление | Длительность при 120 BPM |
|---|---:|
| 1/16 | 125 мс |
| 1/8 | 250 мс |
| 1/4 | 500 мс |
| 1/2 | 1000 мс |
| 1 BAR | 2000 мс |

Деление определяет окно всей кривой и период повторения в HOST SYNC.
В AUDIO новый кик прерывает предыдущий цикл. BAR всегда означает четыре
четверти (4/4), независимо от размера такта проекта. Нулевая глубина участка
кривой оставляет бас без подавления — весь цикл не обязан быть «сжатым».

## Кривая и регуляторы

| Элемент | Действие |
|---|---|
| AMOUNT | Общая глубина подавления, по умолчанию 70% |
| ATTACK | Начальный подъём глубины от текущего уровня, до 100 мс; не задержка старта |
| LENGTH | Положение второй точки и длительность начального участка |
| RECOVER | Время достижения третьей точки |
| TAIL | Участок от предпоследней точки до конца цикла |
| INPUT / OUTPUT | Входной / выходной gain, −24…+24 dB |
| BYPASS | За 20 мс переводит выход на исходный бас, обходя также INPUT/OUTPUT |

Перетаскивание точки по Y меняет глубину, по X — соответствующее время.
Двойной щелчок добавляет точку; правый щелчок удаляет внутреннюю точку.
Допускается до 32 точек. Временные ручки ограничены соседними точками и циклом.
Последняя точка влияет на поздний хвост; ранний следующий кик может не дать
ему прозвучать. Верх кривой — восстановленный бас, низ — максимальный duck.

Шесть кнопок Classic/Punch/Smooth/Long/Swell/Gate выбирают только форму
и временные параметры, сохраняя Amount и уровни. RESET CURVE также возвращает
Amount к 70%. Выбранная неизменённая форма сохраняет подсветку при смене BPM.
Новые экземпляры скруглённые; старые проекты могут сохранять линейную кривую.

Mix сохранён как параметр DAW для совместимости, отдельной ручки нет:
глубина определяется Amount × Mix × curve. При Mix не 100% появляется кнопка
его явного сброса к 100%; старый проект автоматически не изменяется.

## A/B, история и полные пресеты

- A и B содержат параметры и кривую. При первом переходе B копирует текущий A.
- A > B / B > A заменяет другой набор и очищает его историю; копирование само
  не отменяется. Bypass общий и не меняется при переключении A/B.
- UNDO/REDO — по 64 шага на набор. Жест ручкой/точкой или выбор формы — один шаг.
  Новая правка очищает Redo. История переживает закрытие GUI, но не загрузку проекта.
- Оба набора и выбранный A/B сохраняются в проекте DAW. Undo не редактирует
  огибающие автоматизации хоста и не записывает обычные автоматизированные обновления.
- SAVE/LOAD работают с `.kickduckpreset`: все текущие параметры, включая Bypass/Mix,
  точки и скругление. A/B-банки и история в файл не входят. LOAD меняет выбранный
  набор, общий Bypass принимает загруженное значение; другой набор сохраняется.
  Загрузка отменяется одним Undo. Некорректный файл не применяется частично.

## Отображение

Центральный график показывает один завершённый кадр Kick и Bass Out,
начиная с триггера. Новый кадр заменяет предыдущий целиком. Верхний scope —
бегущая полуволна выхода за 2 секунды и синхронная светлая линия фактической GR.

INPUT/OUTPUT показывают Sample Peak по максимуму L/R и RMS средней мощности
каналов (300 мс). Пик удерживается 100 мс, затем спадает на 24 dB/с. GR реагирует
сразу и имеет отображаемое отпускание 150 мс. Это не LUFS и не True Peak.
Один активный канал стерео даёт RMS на 3 dB ниже двух одинаковых каналов.
Превышение 0 dBFS видно числом и красным баром; не допускайте клиппинга дальше в цепи.

Окно открывается 1050×700, изменяется от 1050×620 до 1800×1100.
В маленьком окне шкалы имеют меньше подписей для читаемости.

## Ограничения

Детектор использует фиксированные пороги и может пропустить слабый удар под
громким хвостом. Нет lookahead, oversampling и измерения True Peak/LUFS.
Нет автоматического распознавания send внутри DAW. Миниатюра формы — не
полный пресет настроек. Старые automation ID и состояния сохраняются;
особенности миграций описаны в [CONTROL_SEMANTICS.md](CONTROL_SEMANTICS.md)
и [CONTEXT.md](CONTEXT.md). Прослушивание и измерители DAW остаются окончательной
проверкой результата в конкретном проекте.
