# Changelog

## 1.0.0 — подготовлено 2026-10-17

Первый подготовленный пакет Linux x86-64 (VST3 и Standalone).
GitHub Release и тег автоматически не публиковались.

### Возможности

- Отдельный Kick Sidechain AUX, стереодетектор без противофазного вычитания.
- AUTO / AUDIO / HOST SYNC, музыкальные деления 1/16…1 BAR (4/4).
- Редактируемая скруглённая кривая до 32 точек, шесть форм, стартовый Classic 70%.
- Attack, Length, Recover, Tail, Input/Output; сохранённый legacy Mix.
- Плавные изменения параметров и Bypass 20 мс.
- A/B с копированием и независимым Undo/Redo до 64 шагов.
- Полные файловые пресеты `.kickduckpreset`, загрузка отменяется одним Undo.
- Удерживаемый кадр Kick/Bass Out, непрерывный двухсекундный OUT/GR scope.
- Stereo Sample Peak/RMS/GR с баллистикой и показом превышения 0 dBFS.
- Стартовое окно 1050×700, компактные блоки и нижний ряд кнопок.

### Совместимость и проверки

- Состояние проекта v9, формат файловых пресетов v1; сохранены ID параметров.
- Автотесты состояния, миграций, DSP, GUI, истории, пресетов и конкурентного обмена.
- В 4608 измеренных DSP callbacks не обнаружено C++/перехваченных heap allocations.
- Пользователь подтвердил в REAPER пресеты, восстановление с активным B,
  автоматизацию, несколько экземпляров и offline render.

### Известные ограничения

- Бинарная совместимость подтверждена только в рабочей Linux-среде;
  текущие файлы требуют glibc 2.43+, GLIBCXX_3.4.32 и CXXABI_1.3.15.
- Нет Windows/macOS/ARM-пакетов, lookahead, oversampling, True Peak/LUFS.
- Доля BAR фиксирована как четыре четверти; AUX connected не означает наличие send.
- Полный JUCE/хост под ThreadSanitizer не проверялся; пределы аудита задокументированы.
- Лицензия самого KickDuck1 ещё не выбрана; см. [DISTRIBUTION.md](docs/DISTRIBUTION.md).
