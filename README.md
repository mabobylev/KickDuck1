# KickDuck1

Sidechain-duck плагин для Linux на C++17 / JUCE 8.0.10. Форматы: VST3 и
Standalone. Бас поступает на основной вход, кик — на отдельный AUX
`Kick Sidechain`; кик служит управляющим сигналом и не добавляется в выход.

## Сборка

Нужны CMake 3.22+, компилятор C++17, Git и зависимости Linux для JUCE:
ALSA, X11, FreeType/fontconfig и OpenGL с заголовками разработки.
При первой конфигурации CMake загружает JUCE 8.0.10 через FetchContent.

```sh
cmake -S . -B build-dev -DCMAKE_BUILD_TYPE=Release
cmake --build build-dev --target KickDuck1_VST3 KickDuck1_Standalone KickDuck1Tests -j 3
ctest --test-dir build-dev --output-on-failure
```

Команды также сохранены в `CMakePresets.json`:

```sh
cmake --preset offline
cmake --build --preset tests
ctest --preset dev
cmake --build --preset plugin
```

`offline` использует JUCE из `build/_deps/juce-src`. Если этой папки нет,
выберите `cmake --preset dev` для первичной загрузки. `tests` собирает проверки,
`plugin` — VST3 с автоматической установкой и Standalone. Рабочий контекст
для продолжения в новом чате: [docs/CONTEXT.md](docs/CONTEXT.md).

Если JUCE уже скачан в старом `build/_deps/juce-src`, можно собрать без его
повторной загрузки:

```sh
cmake -S . -B build-dev -DCMAKE_BUILD_TYPE=Release \
  -DFETCHCONTENT_SOURCE_DIR_JUCE="$PWD/build/_deps/juce-src"
```

В `build/` оставлен только локальный исходный JUCE; устаревший CMake-кэш удалён.
Используйте новый каталог сборки; старые артефакты можно сохранить.

Результаты: `build-dev/KickDuck1_artefacts/Release/VST3/KickDuck1.vst3`
и `build-dev/KickDuck1_artefacts/Release/Standalone/KickDuck1`.
После сборки VST3 автоматически копируется в `~/.vst3/KickDuck1.vst3`,
заменяя установленную версию. Чтобы отключить копирование, задайте
`-DKICKDUCK_COPY_PLUGIN_AFTER_BUILD=OFF` при конфигурации.
Тесты можно отключить через `-DBUILD_TESTING=OFF`.

## Использование

Установите VST3 в папку плагинов DAW и обновите её список плагинов.
Разместите KickDuck1 на басовой дорожке; направьте аудио кика на sidechain/AUX
вход этого экземпляра. Проверьте индикатор подключения sidechain.
Standalone удобен для проверки запуска и GUI; маршрутизацию AUX проверяйте
в DAW.

- **Amount** — основной регулятор глубины подавления, увеличенная ручка справа.
- **Attack** — 0–100 мс до глубины первой точки, без предварительной паузы.
  Ручка и горизонтальное перетаскивание первой точки связаны. При 0 мс
  сохраняется мгновенный старт. Участок ограничен положением второй точки.
- **Length** — положение второй точки: значение 0.5 соответствует 25% цикла.
  Масштаб waveform остаётся независимым от Length.
- **Recover** — время от триггера до третьей точки восстановления баса;
  это положение точки, а не постоянная Release обычного компрессора.
- **Tail** — длительность финального участка от предпоследней точки
  до правого края. Это прежняя ручка Attack; старт подавления она не задерживает.
  ID `release`/`attack`, диапазоны и автоматизация сохранены.
- **Mix** — прежний параметр dry/wet, сохранён в состоянии и автоматизации DAW.
  Отдельная ручка убрана: при установившихся значениях DSP использует произведение
  Amount × Mix, поэтому эти ручки дублировали глубину. Новые экземпляры используют
  Mix=100%. В старом проекте с другим Mix появляется кнопка с его значением;
  нажатие возвращает Mix к 100% и меняет звук, поэтому сброс только ручной.
- **Input / Output** — усиление основного сигнала до/после обработки.

## Отображение волн и уровней

В верхней панели между названием и AUX расположен **SIGNAL**: выходной бас
(**OUT**) — односторонняя полуволна с приглушённой зелёной заливкой.
Выше светлой линией рисуется фактическое подавление (**GR**): линия опускается
при увеличении компрессии, учитывает Amount/Mix и не зависит от Input/Output.
OUT учитывает все регулировки уровня; визуальный масштаб использует общий
максимум входа и выхода, с ограниченным увеличением тихих сигналов.
Это непрерывная бегущая история последних **2 секунд**, обновление 30 раз
в секунду: новые данные появляются справа, старые уходят влево.
Оба графика имеют одну временную ось, обновляются между ударами и в режиме BPM.
Противоположные фазы стерео не гасят отображение баса.
Справа надпись LIVE 2 s. Когда аудиоданные не поступают, история сохраняется.


Kick и Bass Output начинаются у левого края одного графика, с общей временной
осью; сначала рисуется Kick, затем Bass Output. Кадр записывается с распознанного
триггера до конца одной доли или до следующего кика. Завершённый кадр целиком
сменяет предыдущий и удерживается: выборки «последних полсекунды» и прокрутки нет.
При частых ударах незаписанная правая часть остаётся пустой, ось не растягивается.
Без кика продолжается захват баса кадрами по одной доле BPM проекта
(120 BPM при отсутствии темпа). При подключённом AUX подавление запускается только киком;
при отключённом AUX кривая повторяется каждую долю BPM, с привязкой к PPQ
транспорта во время воспроизведения. Без PPQ используется непрерывный
темповый цикл; BPM по умолчанию 120.
При остановке аудио сохраняется последний завершённый кадр.

DSP накапливает 1600 пиковых интервалов в трёх фиксированных буферах, без
ограничения старой истории в 96000 samples. GUI резервирует только завершённый
буфер. Для отображения выбирается сильнейший канал каждой стереопары;
бас до/после обработки берётся из одного канала и одного sample.
Input/Output служат в отдельных цветах и отдельном блоке SIGNAL LEVELS;
Предустановки стоят отдельным блоком слева (два ряда по три),
Length/Recover/Tail сгруппированы в середине. Подписи и индикаторы используют
общую геометрию панели при изменении размера окна.

## Структура и проверки

`Source/PluginProcessor.*` — DSP, параметры и сохранение состояния;
`Source/PluginEditor.*` — интерфейс; `DuckingCurve.h` — модель кривой;
`WaveformHistory.h` — история аудио. `Tests/ProcessorTests.cpp` проверяет
сохранение/загрузку, старые состояния, нормализацию точек, обработку без GUI,
Mix/Amount, влияние Length на звук без изменения масштаба времени,
открытие/закрытие редактора и одновременную публикацию кривых.

Точки кривой сохраняются в дочернем дереве `DuckingCurve`, версия состояния —
`stateVersion=8`. Начиная с версии 3 сохраняется режим `curveRounded`;
версия 4 добавила onsetAttack, версия 5 мигрирует геометрические пределы.
Версии 6–8 сохраняют режим запуска и музыкальную длительность; v8 сохраняет Bypass.
Состояния версий 0–2 загружаются с прежними линейными сегментами;
выбор предустановки или RESET CURVE явно переводят форму в скруглённый режим. В старых состояниях точки отсутствуют: при загрузке
устанавливается стандартная кривая. Пользовательские кривые версии 1
сохраняются при миграции; прежняя стандартная форма заменяется исправленной.

## Скругление и предустановки

Новые экземпляры используют общую для GUI/DSP плавную интерполяцию: линия
проходит через точки, скругляет переходы и не выходит за глубины соседних точек.
На экстремумах и крайних точках наклон нулевой. Кнопка ROUND удалена;
старый линейный режим сохраняется при загрузке для совместимости. Выбор любой
предустановки или RESET CURVE включает скругление.

В отдельном блоке слева расположены шесть кнопок с миниатюрами, два ряда по три:
**Classic**, **Punch**, **Smooth**, **Long**, **Swell**, **Gate**. Названия видны под
миниатюрами и в подсказках. Выбор меняет точки и связанные временные параметры,
сохраняет Amount/Input/Output/Mix и уведомляет DAW. Текущая предустановка подсвечена;
после изменения её формы подсветка снимается. Это предустановки формы, не банка
полных настроек плагина. RESET CURVE возвращает Amount к 70%.

## Связь кривой и ручек

Стандартная форма: точки (0%, низ), (25%, чуть выше), (50%, верх),
(90%, чуть ниже верха), (100%, низ). Amount по умолчанию 70% (только новый экземпляр и RESET CURVE;
сохранённые значения проектов не заменяются).
Кик запускает полный цикл длительностью одной четвертной доли (500 мс при
120 BPM). Форма проигрывается после затухания кика; при подключённом AUX без триггера бас проходит
без подавления. Отключённый AUX включает повторение кривой по BPM. Следующий распознанный удар запускает цикл заново.

Детектор использует максимум модулей каналов AUX, порог 0.02 (около −34 dBFS)
и гистерезис 0.008 (около −42 dBFS). Быстрая пиковая огибающая затухает с
постоянной 3 мс; новый всплеск выше 1.6 × медленной огибающей (80 мс)
распознаётся и поверх хвоста. Между запусками выдерживается минимум 30 мс.
Слабый удар, скрытый более громким хвостом, может не распознаться;
пороги пока фиксированные. Recover/Tail относятся к положению точек кривой.

Input/Output плавно меняются в dB, Amount/Mix — линейно, за 20 мс.
Изменения кривой, Length/Recover/Tail и возврат к dry ограничены скоростью
изменения глубины: полный диапазон за 2 мс. При Attack=0 новый удар устанавливает глубину
первой точки сразу. При Attack>0 начальный участок плавно достигает её глубины;
повторный удар продолжает с текущего подавления без скачка обратно к dry.
При prepareToPlay сглаживание начинается с текущих параметров.
GR учитывает фактический Mix.

Перетаскивание первой точки по X обновляет Attack, второй — Length, третьей — Recover,
предпоследней — Tail через параметры DAW; соответствующие ручки вращаются.
По Y редактируется глубина конкретного участка. Amount показывает максимальную
глубину всей кривой: он меняется при изменении максимума, сохраняя остальные
видимые глубины. Input/Output относятся к уровням сигнала; прежний Mix сохранён для совместимости.
Ручки обратно изменяют отображаемую и обрабатываемую форму.
Точки сохраняют порядок; недопустимые позиции ограничиваются соседями.

`RESET CURVE` восстанавливает пять точек и связанные ручки в любом экземпляре,
включая ранее сохранённые проекты. Временные ручки управляют точками кривой: Tail/Recover имеют
диапазоны 1000/4000 мс. Их смысл соответствует предыдущей сборке, изменены
только подписи Attack → Tail и Release → Recover.

Последняя точка задаёт конечную глубину и форму позднего хвоста. При 120 BPM
край находится на 500 мс; следующий распознанный кик запускает цикл заново.
Если он приходит раньше, конечная часть может не прозвучать. После цикла бас
возвращается к dry с прежним сглаживанием. Для ducking без повторного провала
в конце используйте Punch/Smooth/Long/Gate, либо поднимите конечную точку до
нулевой глубины. Подробнее: [docs/CONTROL_SEMANTICS.md](docs/CONTROL_SEMANTICS.md).

План и принятые по переписке требования: [docs/PLAN.md](docs/PLAN.md).
В интерфейсе показаны RMS; ложная подпись LUFS убрана.
Стереоизмерители Peak/RMS реализованы. Прослушивание, маршрутизация и внешний вид требуют проверки в DAW.

RECOVER и TAIL ограничены соседними точками и текущей длительностью доли.
Числа и ход ручки соответствуют достижимому положению; при изменении BPM
диапазоны обновляются. ID и прежние диапазоны параметров DAW сохраняются,
поэтому старые внешние значения автоматизации DSP ограничивает геометрией.

## Измерители уровней

INPUT/OUTPUT — sample Peak по максимуму обоих каналов, после соответствующих
усилений. Противоположные фазы не гасят показания. RMS — корень из средней
мощности каналов с экспоненциальным усреднением 300 мс; это не LUFS.
Один активный канал стерео даёт RMS на 3 дБ ниже пары одинаковых каналов
при одинаковом Peak. Для моно мощность берётся без деления пополам.
Пики удерживаются 100 мс и спадают на 24 дБ/с. GR-индикатор учитывает Mix,
реагирует мгновенно и отпускает с постоянной 150 мс; это только отображение.
Верхняя линия GR сохраняет точную историю фактического подавления.
Баллистика рассчитывается по sample clock и не зависит от размера блока.
Бар достигает верха при 0 dBFS, становится красным при 0 dBFS и выше;
цифры показывают превышение. Это sample Peak, не oversampled True Peak.


## Музыкальный запуск

Небольшие кнопки под временными ручками в среднем блоке выбирают AUTO, AUDIO и HOST SYNC.
AUTO выбирает Audio Trigger с включённым AUX и Host Sync с отключённым;
тишина между киками не переключает режим. AUDIO запускает кривую только
от кика, HOST SYNC — от сетки транспорта независимо от AUX. При остановке
Host Sync возвращает dry; без PPQ во время playing цикл свободный,
без BPM используется 120 BPM. Плагин видит состояние шины, а не send в DAW.

Кнопки 1/16, 1/8, 1/4, 1/2 и 1 BAR задают длительность всей кривой и
интервал повторения в Host Sync. При 120 BPM это 125, 250, 500, 1000 и
2000 мс. 1 BAR означает четыре четверти (4/4), независимо от размера такта.
Короткие деления подходят для быстрого восстановления баса, длинные —
для протяжённого эффекта. Форма глубины внутри цикла задаётся точками и
ручками; новый кик в Audio Trigger перезапускает цикл.

Состояния v7 с автоматическим выбором загружаются с фактически использовавшимся
циклом 1/4, даже если неактивный тогда параметр Division имел другое значение.
Прежние ID и диапазоны параметров сохранены. Legacy AUTO может сохранять
свободный цикл при остановке; нажатие AUTO явно включает современный режим.

## Bypass и аудит

BYPASS переводит весь выход на исходный бас за 20 мс, обходя Input/Output
gain и ducking. При выключении плавно возвращается обработанный сигнал.
Детектор и clock продолжают работать; bypass сохраняется и автоматизируется
через параметр DAW. Выделений памяти в тестируемом DSP не обнаружено;
протокол waveform/reset усилен и проверен конкурентным тестом. Подробности
и пределы проверки: [docs/REALTIME_AUDIT.md](docs/REALTIME_AUDIT.md).
